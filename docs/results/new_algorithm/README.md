| Bug | 位置 | 修复 |

**修复后行为变化（如实报告）**：切换决策的 HV 数值修正后，DTLZ2 上的切换试验从"全部拒绝"变为"全部采纳"，HCEA 在 DTLZ2 上的 IGD 随之变差（详见 §4 前后对比）。这说明修复前的"DTLZ2 30/30 保持 APD"是错误 HV 公式造成的假象，而非算法机制本身的判别能力。

## 1. 算法设计

**HCEA（Hybrid Convergence-Environmental Archive）** 是一个双机制多目标进化算法，核心是**用超体积（HV）在线验证的机制切换**——算法在前半程用参考向量引导的 APD 选择快速收敛，并在固定检查点用 HV 实测决定是否切换到 SMS-EMOA 式超体积精化。

### 机制 A：收敛主导（参考向量 + APD 选择）
- 静态参考向量：UniformPoint(N, M, 'NBI') 初始化一次，不做 RVEA 的目标范围自适应缩放。
- 每代：随机父代池（randi）→ SBX + 多项式变异产生 N 个子代 → 合并后对每个参考向量保留 APD 最小的解，不足 N 个时按 APD 顺序回填（恒种群）。
- APD 含 theta 退火：theta = (gen/maxGen)²，早期强调收敛距离、后期强调角度分布。

### 机制 B：分布精化（SMS-EMOA 式增量超体积选择）
- 每代 N 次「并入-删除」：随机 2 父代产生 1 个子代（OperatorGAhalf）→ 并入种群 → 在末级前沿内删除超体积贡献最小的解（2D 精确贡献，SMS-EMOA 标准式；边界解贡献 = ∞ 永不删除）。

### 核心机制：HV 验证的自适应切换
- 在第 50%、60%、70% 代三个检查点各尝试一次切换：用机制 B 运行 1 代，若种群超体积（参考点 = 1.1 × 当前目标最大值，**标准 2D HV 公式**）提升，则永久切换到机制 B；否则保持机制 A 并在下个检查点重试。
- 切换决策完全在线：只使用当前种群目标值，不使用真实 Pareto 前沿信息。
- 修复后实测（30 种子 × 2 问题）：ZDT1 **30/30** 切换；DTLZ2 **30/30** 切换（修复前为 0/30，见 §4 分析）。

### 辅助机制
- 末端 HV 抛光：最后 10% 代数内每 5 代对 HV 贡献最低的解（SMS-EMOA 标准贡献式 + 传入参考点）做 3 次小扰动变异，保留贡献最大的候选（评估计入 nFE）。
- nFE 如实累计：20100（正常代）+ 每次切换试验 100 + 每次抛光 3。修复后 HCEA 的 nFE 为 ZDT1 20115 / DTLZ2 20115（两问题均在 50% 检查点采纳切换）。

### 结论（诚实表述，公式修复后）

- **HCEA 在 ZDT1 上仍居第 2（0.003746，仅落后 SMSEMOA 2.7%，且方差更小）；在 DTLZ2 上跌至第 6（0.005710），不再具有"两问题均前 2"的优势。** 修复前的该结论作废。
- **切换行为变化的解释**：修复前 DTLZ2 上"0/30 切换、保持 APD、IGD 0.0042"是错误 HV 公式的产物——旧公式低估/错配区间权重，导致试验代 HV 恰好未提升。用标准 HV 公式后，SMS 精化在 DTLZ2 上确实提升超体积（30/30 采纳），因此算法按设计切换。但 **HV 最优分布与 IGD（弧长均匀）指标在凹前沿上并不一致**：切换到 SMS 后 HCEA 的 DTLZ2 表现与 SMSEMOA 几乎相同（0.005710 vs 0.005700），这是机制 B 就是 SMS-EMOA 算子的自然结果。
- **本质教训**：HCEA 的切换目标是最大化超体积，不是 IGD；两个指标在 DTLZ2（凹前沿）上出现分歧。这是一个真实的算法行为，如实报告，不做任何为挽回 IGD 的额外改动。
- HCEA 现在的画像：ZDT1 上接近 SMSEMOA（0.003746 vs 0.003644）；DTLZ2 上与 SMSEMOA 无显著差异（p=0.888），差于 MOEAD/SPEA2。

## 7. 局限性（诚实声明）

- 仅在 2 目标 ZDT1/DTLZ2 上验证；HV 相关计算针对 M=2 精确实现，M≥3 需采样近似。
- 切换检查点（0.5/0.6/0.7 × maxGen）、theta 指数 α=2、HV 参考点 1.1 倍为通用默认值，未对测试问题做网格调参，但开发期消融见过测试问题结果，存在选择偏倚。
- HV 验证只做 1 代试验，存在随机波动；3 个重试检查点缓解该问题。
- 修复轮次揭示：HV 与 IGD 在凹前沿上可能分歧；以 HV 为切换判据不保证 IGD 最优。
