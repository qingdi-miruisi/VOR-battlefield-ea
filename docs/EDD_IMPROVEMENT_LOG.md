### 三算法核心机制（读源码结论）

**FDSEA（SWEVO 2026，频率域搜索）**：双种群架构——P1 频率域开发种群（FRGA/FRDE
对 2K+2=12 个频率域参数做进化，Cal_Dec 解码成全维决策，全维共享频率域基函数）+
P2 决策域 Hybrid 种群（gama 控制）。每代双向迁移 10 个个体。频率域参数空间只有 12 维，
开发/搜索都在低维参数空间做，**天然规避 300D 决策空间的全维搜索失效**。
收敛快（LSMOP1 IGD 0.12 vs EDD 0.86，差 7 倍），但参数空间低维导致**极端多样性的
front 可能略窄**（HV 在 LSMOP6/7 也接近 0，与 EDD 相同——说明这两题本身 HV 难）。

**GDVTSF（SWEVO 2025，代际差向量三熵结构）**：WOF 双种群 + GDVTSO 三蜂群（p1/p2/p3
按适应度轮换）+ 模糊差异向量 FDV（0~60% FE 用截断/取整算子，60% 后全评估）。
核心是 **kmeans 聚类（K=5）+ 代际差向量 GDV**：每代重聚类决策空间，算代际中心差
方向作定向速度分量，三蜂群 TSO 式开发。决策空间做聚类+有向速度，**保留了 300D
全维开发能力**，同时用三蜂群+模糊差异控制多样性。

**MOEA-IB（IEEE TEVC 2026，改进基准法）**：WOF（权重优化框架）双种群，子代用
MOEA-IB 局部搜索。WOF 对问题做**决策变量分组（2~3 组）+ 权重空间开发**，
每组用 MOEA-IB 优化权重组，再把优化后的权重映射回全维决策。本质是
**把 300D 决策问题分解成低维权重优化 + 变量重组**，与 FDSEA 频率域思路同源
（都是"低维参数开发 + 全维映射"）。

**共同点 = LSMOP 制胜关键**：三者都**不是直接在 300D 决策空间做全维进化**，
而是用某种降维参数化（频率域 / 权重 / 聚类中心）做开发，再映射回全维。
EDD v12 的 DSG 是"3 段模糊骨架 + 灰狼定向"，**每子代只能做单父局部移动**，
在 300D 下 front-1 长期停滞（LSMOP1 0.86 而 FDSEA 0.12 的根本原因）。
EED 的 front-1<N 补齐机制进一步稀释了收敛能力。这是 EDD 输的最可能机制根源。

### 诊断结论

EDD 输的核心机制：**(1) 单父有向采样（DSG 段内）在 300D 下开发能力不足**——
三新算法都用"双源/低维参数"开发，单父局部移动无法在有限 FE 内压缩 front-1。
**(2) EED front-1 裁剪后按 front 层次补齐稀释收敛**（与 v10 已知的 LSMOP6
PPS 崩溃同源）。**(3) polishHV 在 300D 下用 1% 局部扰动 ≈ 3 维随机，无效**。

### 候选改进方案（机制级，非调参）

**方案 A（首选）：双源有向交叉 + 全维 polish**
- 把 eedGeneration 的 70% 子代从"单父 dsgOperator 段内采样"改为"2 父代有向 SBX
  交叉（按目标贡献排序取父，beta=1/15）"，30% 保留旧 DSG（全局探索）。
  借鉴 FDSEA/MOEA-IB 的双源开发思路，但保持 EDD 的 EED 选择框架（不引入新种群）。
- 0.8G 起把 polishHV 换成"front-1 决策变量做 DSG 段内采样"（全维有效，替代 1% 扰动），
  子代并入 EED 选择，FE 计入 totalFE。
- 动机：双源交叉补齐开发能力（FDSEA 赢的机制根源），全维 polish 修复末端收敛；
  FE 预算不变（N=100 G=200 maxFE=20100），ParetoFront/参考点不变。

**方案 B（备选）：EED 自适应 epsilon 网格 + 角度多样性联合选择**
- 旧 EED 固定 epsGrid=10，front-1 数量骤减时网格过粗。改为 epsGrid 随 front-1
  数量自适应（front-1<N 时加密），并在 front-1 内加"到原点距离 + 角度多样性"
  联合选择（借鉴 MOEA-IB 的 APD 式角度项），替代纯按 front 层次补齐。
- 动机：修复 front-1<N 时的收敛稀释（LSMOP6 PPS 崩溃同源）。

**方案 C（若 A+B 仍不够）：引入三蜂群 TSO 开发（借鉴 GDVTSF）**
- 把 30% 探索子代改为三蜂群轮换（按适应度分 3 群，群间 TSO 式定向开发），
  直接移植 GDVTSF 的 triple_swarm_select 机制。
- 动机：GDVTSF 在 LSMOP1-2 与 EDD 差距最大（-86%/-82%），其三蜂群开发可能是关键。

## 改进轮次记录（追加）

### 轮次 1：方案 A（双源有向交叉 + 全维 polish）

- **修改机制**：`algorithms/EDDV2.m`（类名 EDDV2，继承本地 ALGORITHM 基类）
  1. [改进A] `eedGeneration` 子代生成：70% 子代改为 2 父代有向 SBX 交叉（P1/P2 随机
     不同父代，逐维 beta=1/15 编码 + 符号 + 50% 不交换），30% 保留旧 DSG 段内采样
     （全局探索）。动机：旧版每子代=单父灰狼局部移动，300D 下 front-1 停滞；双源
     交叉借鉴 FDSEA/MOEA-IB 的双源开发思路。
  2. [改进B] 0.8G 起全维 polish：用 front-1 决策变量做 DSG 段内采样生成 10%N 子代
     并入 EED 选择（替代旧 polishHV 的 1% 局部扰动——300D 下 1% 扰动仅 3 维随机，
     无效）。FE 计入 totalFE。
  3. 辅助：epsilon 网格随 front-1 数量自适应加密（front-1<N 时 curGrid 降）。
- **公平性**：N=100 G=200 maxFE=20100 不变；ParetoFront(500)/refPoint(1.1*maxPF) 不变；
  种子 1:30 不变；FE 预算不变（polish FE 计入 totalFE）。
- **LSMOP1 s1 冒烟**：旧 EDD IGD=0.8579 → EDDV2 IGD=0.8603（-0.3%，持平未崩），
  HV 0.1244→0.1223。
- **判定**：冒烟未改善，**方案 A 单点不够**（FDSEA LSMOP1 IGD=0.1209，v2 仍 0.86，
  差 7 倍）。双源交叉未带来 front-1 的实质压缩——可能是 SBX 在 300D 全维上仍
  不够"有向"（FDSEA 赢在 12 维频率域参数空间开发，非决策空间）。
- **30 种子正式结果（v2_lsmop_log.txt + compare_v2_log.txt）**：
  | 题 | EDDV2 IGD中位 | 旧EDD IGD中位 | 变化 | 胜负(V2:旧) | HV中位(旧→V2) |
  |---|---|---|---|---|---|
  | LSMOP1 | 0.8599 | 0.8579 | -0.2% | 0:30 | 0.1244→0.1227 |
  | LSMOP2 | 0.4994 | 0.4253 | -17.4% | 0:30 | 0.4352→0.3601 |
  | LSMOP3 | 1.0625 | 0.8628 | -23.1% | 0:29(1平) | 0.1200→0.0000 |
  EDDV2 全胜题数 = 0/3。**方案 A（双源交叉+全维polish）正式失败**，且 LSMOP2/3
  的 HV 显著退化（LSMOP3 HV 直接归零）。
- **下一步**：方案 C（三蜂群 TSO + kmeans GDV，移植 GDVTSF）——但冒烟（smoke_v3_log）
  已测：LSMOP1 s1 IGD 0.8579→1.4（-63% 恶化），HV 0.1244→0。**方案 C 冒烟也失败**。
  根因：GDV/TSO 直接搬决策空间 300D，kmeans K=5 群半径大 + TSO 混沌变异把
  front-1 打散（GDVTSF 在 LSMOP2 是赢的但 LSMOP1 靠 WOF 双种群框架，单种群 EDD
  搬不走其开发强度）。
- **第 3 轮方案（最后机会）**：方案 D——直接移植 FDSEA 的 12 维频率域傅里叶参数化
  开发 + 全维映射（Cal_Dec：x_j = c + Σ a_k·cos(k·ω·j + φ_k)），这是 IGD 第1
  算法的核心机制。在 EDD 框架内保留 EED 选择 + EDD epsilon 多样性，把子代生成
  从 DSG/双源交叉换成"12 维参数空间的 SBX + 多项式变异 → Cal_Dec 映射"。
  这是真正的机制级改进（把搜索投到低维参数空间，而非 300D 决策空间硬开发）。
  公平性：N/G/FE/PF/参考点不变。
- **状态**：轮次 1（A）+ 轮次 2（C）双双失败。轮次 3（D）为最后机会。
  若 D 仍不能让 EDD 拿回 Friedman #1，按协议停止改进并报告用户（3 轮上限）。

### 轮次 2：方案 C（kmeans GDV + 三蜂群 TSO）

- **修改机制**：`algorithms/EDDV3.m`（类名 EDDV3，继承本地 ALGORITHM 基类）
  1. [改进C1] kmeans K=5 聚类决策空间 + 代际中心差 GDV（移植 GDVTSF cal_GDV）。
  2. [改进C2] 三蜂群 TSO 开发（移植 GDVTSF triple_swarm_select + operator_GDV_TSO）：
     种群分 p1/p2/p3 三群，群间 TSO 式定向 + gBest 方向 + GDV 有向速度 + 混沌变异。
  3. 保留 EED front-1 层次选择框架。
- **冒烟结果（LSMOP1 s1）**：旧 EDD IGD=0.8579 → EDDV3 IGD=1.4（-63.1% 恶化），
  HV 0.1244→0.0（归零），PPS=99。**方案 C 冒烟直接失败，未进 30 种子**。
- **判定**：失败。kmeans K=5 在 300D 下群半径过大 + TSO 混沌变异打散 front-1，
  单种群 EDD 框架吃不下 GDVTSF 的双种群 WOF 开发强度。诚实记录，不进 3.3。
- **状态**：失败，记录在 `results/smoke_v3_log.txt`。

### 轮次 3：方案 D（FDSEA 12 维频率域傅里叶参数化）— 最后机会

- **修改机制**：`algorithms/EDDV4.m`（类名 EDDV4，继承本地 ALGORITHM 基类）
  1. [改进D] 低频傅里叶参数化开发（移植 FDSEA Cal_Dec + FRGA 参数空间 SBX+多项式变异）：
     种群双表示 θ∈[0,1]^12 + x∈[0,1]^300，每代 12 维参数空间开发 → Cal_Dec 映射 300D。
  2. 保留 EED front-1 + epsilon 网格 + 角度多样性选择。
- **冒烟结果（LSMOP1 s1）**：旧 EDD IGD=0.8579 → EDDV4 IGD=1.222（-42.5% 恶化），
  HV 0.1244→0.0（归零），PPS=97。**方案 D 冒烟失败，未进 30 种子**。
  根因：Cal_Dec 的余弦基 x_j = c + Σ a_k·cos(kωj+φ_k) 假设决策变量沿 j 有平滑余弦结构，
  但 LSMOP1 的 300 维决策→目标映射对每个维度都是独立贡献（无 j 方向低频结构），
  余弦基表达力不足 → front 无法向 IGD 0.12 量级压缩。FDSEA 赢的真正原因是
  **双种群（P1 参数域 + P2 决策域 10 个体互换 + gama 自适应）**，单种群 EDD 搬不走。
- **判定**：三轮方案（A 双源交叉 / C TSO+GDV / D 傅里叶参数化）全部失败。
  按阶段3 EDD保第一协议**改进轮次上限 = 3 轮**，已用完。
  **结论：在机制级改进约束下（N=100 G=200 FE 预算不变、PF/参考点/种子不变、
  FDSEA/GDVTSF/MOEA-IB 源码只读），未能让 EDD 重新拿回 Friedman #1**。
  三轮冒烟/30种子证据：
  | 轮 | 方案 | LSMOP1 IGD | HV | 30种子(1-3) | 判定 |
  |---|---|---|---|---|---|
  | 1 | A 双源交叉+全维polish (v2) | 0.8603 | 0.1223 | 0:30/0:30/0:29 全输 | 失败 |
  | 2 | C kmeans GDV+TSO (v3) | 1.4 | 0.0 | 冒烟即崩 | 失败 |

**EDD Friedman #1 硬门未通过**——13 算法 LSMOP1-9 Friedman 中 FDSEA 第1、EDD 第4（combined），

**红线遵守**：三轮均无数据篡改、PF/参考点/种子/FE 预算未变、新算法源码只读、

### 轮次 4：双种群 EDD（架构级·强化版a）— 最后一轮（解除 3 轮上限后用户指定）

### 机制诊断（f_theta + reanchor 代码三问，红线：不掩盖）

**问题1（θ 凸组合几何效应）**：`f_theta` 的 x=reps'*w' 中 w=θ/Σθ 是归一化非负权重
（SBX 后 θ∈[0,1]、reanchor one-hot+距离衰减非负）→ **x 严格落在 reps 凸包内**。
B 半 DSG 的灰狼定向 `cand=wRand*cand+wDir*a*r1*(segBest-cand)`（a=2(1-i/N)、r1∈[-1,1]）
**可外推到凸包外**。→ A 半探索范围严格 ⊂ B 半，A 产物在 eedSelect 里被 B 挤掉，
v6 退化成"B 半 DSG + EED 选择"，总开发强度 < 旧 EDD。**成立。**

**问题2（reps 加权抹平 DSG 有向性）**：θ 空间 SBX 是仿射插值（线性），多项式变异是
θ 维局部微扰，映射回 D 维后 x 随 θ 的变化被 reps 几何"压平"（若 reps 集中，θ 大变化
只移动 x 到凸包内相近位置）。对比 B 半 DSG 非线性定向（r1 随机符号→步长可正可负、
幅度可超 1→跳出当前段）。**θ 线性映射抹平 DSG 非线性有向性。成立。**

**问题3（A 半弱机制消耗 50% FE）**：run() 里 A 半 50 FE 做 θ 凸组合（探索限凸包内、
开发弱），B 半 50 FE 做 DSG（=旧 EDD 100 FE 的强度减半）。v6="A 半弱机制 50 FE + B 半
强机制减半 50 FE"，有效开发强度 ≈50% DSG + 弱凸包贡献 < 旧 EDD 100% DSG。**成立，
是 DTLZ2_M5 反向劣化的直接原因。**

**诊断结论：反向劣化是架构性、不可修的。** 三问同指 θ 凸组合的**凸包限制是 EDD 网格
坐标隐空间机制的固有几何缺陷**——修不了（唯一修法是 θ 带符号/可外推参数化，但那直接
滑向 FDSEA 频率域，违反"不许照搬 FDSEA 主路径"红线）。
