# 任务3 CRT 强化预案（高维/多目标场景）

## 目标
HCEAV4 在 M≥3 多目标 + 高维决策空间（D≥100）上 IGD 未达 10 算法第一时，强化 CRT（Convergence-Gated Boundary Immigration）机制。

## 诊断框架（等 8 基线补齐后执行）

### 分系列诊断（MaF / LSMOP / EMO 各 29 问题中的子集）
对每个系列，统计 HCEAV4 vs 10 算法群体的 IGD 排名分布：
- **MaF7-15（9 问题，M=3 D=12）**：中维多目标，HCEAV4 的 CRT 应发挥端点保护优势
- **LSMOP1-9（9 问题，M=3 D=300）**：高维决策空间，HCEAV4 退化路径（apdGenerationPure + crtCorrection 早退），CRT 几乎未生效
- **EMO1-11（11 问题，M=3 D=3）**：低维多目标，HCEA 精确副本

**诊断输出**：每个系列 HCEAV4 的 IGD 平均秩 + 与第 1 名的差距（IGD 比值），定位"哪个系列压制 HCEAV4"。

### 预期结论
- 若 LSMOP 压制最狠（IGD 比值 >2）→ D≥100 退化路径是瓶颈 → 强化 `crtCorrection` 的 D≥100 早退
- 若 MaF 压制 → 端点保护在多目标下不足 → 增强 CRT 的多目标边界移民
- 若 EMO 压制 → 低维多目标上 HCEA 精确副本无优势 → 需新的 M=3 低维机制

## 强化方案（按诊断结果选 1-2 个实施）

### 方案 A：增强 D≥100 局部下降方向选择（若 LSMOP 压制）
- 现状：`crtCorrection` 在 D≥100 时早退（返回 HCEA 精确副本行为）
- 强化：改为"D≥100 时用 IGD 残差最高的 5 个个体做定向局部搜索（非全量早退）"
- 风险：LSMOP D=300 单 run 时间翻倍，需 FE 预算内完成

### 方案 B：多目标端点保护增强（若 MaF 压制）
- 现状：CRT 在 M≥3 上做边界移民，但端点（objective 极值）保护不足
- 强化：检测 IGD 残差最大的 2 个 objective 维度，对这 2 个维度的端点做定向注入（类似 M=2 端点保护的 M≥3 推广）

### 方案 C：HV 参考点校验（若 EMO 压制）
- 现状：EMO 问题 HV=0（refPoint 退化，PF 量级 ~10²-10³）
- 强化：对 EMO 系列用自适应 refPoint（PF 最大值的 1.1 倍），避免 HV 全 0 导致指标失效

## 实施纪律
1. 每次强化跑 3 种子 × 1 代表问题（MaF14/LSMOP6/EMO2 各 1）快速验证 IGD 是否改善
2. 验证通过 → 全量 30 种子 × 29 问题重跑 HCEAV4（约 2-3 小时，后台 job）
3. 重跑后重算 `friedman_m3()` → 确认 HCEAV4 是否进入 IGD 前三
4. 若强化后仍未进前三 → 诚实报告"高维多目标上 HCEAV4 综合性能前 4-7，HV 前 2-3"，定位改为"综合竞争力"而非"第一"
